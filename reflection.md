# Reflection (Prompt Engineering Assignment)

This project reinforced that prompt engineering is behavior design, not just wording design. Early versions of the prompts produced answers that were correct but too generic, which made all personas sound similar. The quality improved once I introduced clearer role framing, strict response constraints, and stronger examples. In other words, model output became more useful only when the input instructions became specific and testable.

Few-shot examples had the biggest impact on persona separation. Anshuman-style responses became more systems-oriented and bottleneck-driven. Abhimanyu-style responses became more execution-focused with faster feedback loops and deliverables. Kshitij-style responses became calmer and more foundational, with emphasis on consistency and long-term compounding. These patterns stayed stable across multiple user questions, which suggests that examples guide tone and structure more reliably than broad style instructions.

Constraints were the second major quality lever. Rules like "avoid hype," "avoid vague theory," and "avoid instant-success promises" reduced drift and made outputs safer and more authentic. A fixed response format (4-5 sentences ending with one question) also improved usability because answers stayed concise and naturally conversational. The model had enough room to reason while still remaining predictable for users.

On the product side, the redesigned UI made evaluation easier. I kept the same interaction pattern (switch persona -> reset conversation -> continue chat) so behavior stayed consistent, but changed the visual system completely to improve clarity and focus. The dashboard layout, persona control panel, and quick prompt chips now make persona comparison faster. Typing and sending states also make request status clearer.

If I continue this project, I would add persona-specific memory so users can compare short-term coaching trajectories rather than one-off responses. I would also create a small benchmark set of fixed prompts and score each persona for consistency, actionability, and tone adherence. Overall, the key lesson is that good AI UX comes from combining strong prompt architecture with a frontend that makes those prompt differences easy to observe.
